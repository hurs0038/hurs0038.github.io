HTML tags I've learned.


Paragraph
The paragraph tag is used for simple body text.
Heading
The heading tags are used to create large text for headings.
Line break
The line break tag is used to create a break in the text.
Abbreviation
The abbreviation tag is used to define abbreviations when hovered over.
Block quote
The block quote tag is used to create an indented quote.
